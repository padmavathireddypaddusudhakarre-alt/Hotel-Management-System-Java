# Hotel Management System

## Description

A simple Java-based Hotel Management System that collects customer details, room number, number of days stayed, and calculates the total hotel bill.

## Features

* Enter customer name
* Enter room number
* Enter number of days
* Calculate total bill
* Display booking details

## Technologies Used

* Java
* Scanner
* Basic Java programming

## How It Works

The program takes customer information as input and calculates the bill based on the number of days.

**Room charge:** ₹1000 per day

### Example

```text
Customer: Mimi
Room: 101
Days: 3
Bill: Rs.3000
```
